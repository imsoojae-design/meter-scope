# 수도미터 USB 시뮬레이터 (계량기 / Slave 역할)

서울특별시 디지털계량기 프로토콜 V1.2를 따르는 **계량기(Slave)** 시뮬레이터입니다.
검침단말기(Master)가 보내는 검침요청(REQ_UD2)을 USB-TTL 시리얼 포트로 수신하여,
검침값 회신(REP_UD, Long Frame)을 자동으로 응답합니다.

이번 재작성에서 해결한 핵심 사항:

## ★ TX/RX Low level 강제 (필수 요구사항)
- 프로그램 실행 직후, 그리고 포트 연결 직후 **TX/RX 오실로스코프가 즉시 Low 레벨 한 줄로 표시**됩니다.
- 실제 하드웨어 TX 라인도 포트를 여는 즉시 `SetCommBreak()`로 강제 Low(전기적 절연) 상태가 되며,
  검침요청을 받아 응답하는 짧은 구간에만 `ClearCommBreak()`로 High 전환 후 다시 Low로 복귀합니다.
  (프로토콜 규정: "전자식 수도계량기는 검침단말기와 통신을 하지 않는 상태에서는
  검침단말기와 전기적으로 절연상태이어야 한다.")

## 오실로스코프 재작성
- 기존 버전은 줌/스크롤 상태 관리 로직에서 문제가 있어 파형이 아예 안 보이는 버그가 있었습니다.
- 이번 버전은 **항상 전체 파형을 컨트롤 폭에 자동으로 맞춰 그리는 방식**으로 단순화하여
  화면에 아무것도 안 나오는 문제의 원인을 원천 차단했습니다.

## 파일 구성
```
meter_simulator.c   메인 프로그램 (계량기 시뮬레이터, Win32 GUI)
oscilloscope.c/h    오실로스코프 커스텀 컨트롤 (v2, 자동맞춤 렌더링)
.github/workflows/build.yml   GitHub Actions 자동 빌드 (MinGW)
```

## 로컬 빌드
```bash
gcc -o MeterSimulator.exe meter_simulator.c oscilloscope.c \
  -lcomctl32 -luser32 -lgdi32 -mwindows -O2 -municode -Wall
```

## 검증
`build_rep_frame()`이 만드는 Long Frame은 프로토콜 문서의 예제
(기물번호 09-123456, 15mm, 검침값 12345.678)와 바이트 단위로 완전히 일치함을 확인했습니다:

```
68 0F 0F 68 08 01 78 0F 56 34 12 09 00 1C 13 78 56 34 12 78 16
```

## 사용 방법
1. COM 포트 선택 → **연결** (TX 즉시 Low 절연 상태로 전환, 오실로스코프 Low 표시)
2. 기물번호 / 구경 / 검침값 / 소수점자리 / 슬레이브 주소 입력
   (필요 시 과부하/역류/누수/저전압 체크박스로 경보 상태 테스트)
3. 검침단말기(Master)에서 REQ_UD2 전송 시:
   - RX 오실로스코프에 수신 파형 표시
   - 프로토콜 타이밍(Low 50ms → High 35ms → 데이터 전송 → High 50ms → Low 복귀)에 따라
     실제 TX 라인 제어 및 REP 응답
   - TX 오실로스코프에 송신 파형 표시
4. **연결 해제** 시 TX 라인 Break 해제 후 포트 닫힘

## 제한사항 / 참고
- 오실로스코프는 매 요청마다 초기화되어 **가장 최근 1건의 송수신 파형만** 표시합니다
  (여러 건 누적 스크롤은 지원하지 않음 — 필요하시면 요청해주세요).
- Low/High 대기시간은 프로토콜이 허용하는 범위(0~100ms, 20~50ms) 내 중간값을 사용했습니다.
